# Rules Docs

## Workflow

1. **Pre-scan**: identify affected docs pages and ownership boundaries.
2. **Remediation**: update content with concrete source anchors and canonical governance references.
3. **Verification**: validate links/paths and remove stale references.

## Contracts

- Documentation should not contain TODO/FIXME/TBD placeholders.
- Documentation should not contain absolute system paths.
- Markdown files should not have trailing whitespace.
- Markdown files should have at least one heading.
