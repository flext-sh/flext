## Migration Pattern

### Before (FORBIDDEN)
```python
from typing import cast
from flext_core.models import m

def process_config(data: dict) -> str:
    config = cast(m.Core.Config, data)
    return config.app_name
```

### After (REQUIRED)
```python
from flext_core.utilities.guards import Guards
from flext_core.models import m

def process_config(data: dict) -> str:
    if Guards.is_config(data):
        return data.app_name
    raise ValueError("Invalid config")
```

### Step 3: Replace cast() with TypeGuards (0.3 days)

For each file with cast():

1. **Remove import**:
   ```python
   # REMOVE: from typing import cast
   ```

2. **Add import**:
   ```python
   from flext_core.utilities.guards import Guards
   ```

3. **Replace usage**:
   ```python
   # BEFORE
   config = cast(m.Core.Config, data)
   
   # AFTER
   if Guards.is_config(data):
       config = data
   else:
       raise ValueError("Invalid config")
   ```

4. **Update function signature if needed**:
   ```python
   # BEFORE
   def process(data: object) -> str:
       config = cast(m.Core.Config, data)
       return config.app_name
   
   # AFTER
   def process(data: object) -> str:
       if not Guards.is_config(data):
           raise ValueError("Invalid config")
       return data.app_name
   ```
