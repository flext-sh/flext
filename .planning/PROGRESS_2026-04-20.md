## Root Cause Analysis

**Problem**: `t.JsonValue` recursive type composition:

```python
type Container = Scalar | Path | ScalarMapping | ScalarList | JsonValue
```

This causes:

1. **Type explosion** - Unions expand to 20+ alternatives
2. **Assignment incompatibility** - dict vs Mapping narrowing
3. **Return type mismatches** - dict[K, V] can't assign to t.MappingKV[K, V]
4. **Pervasive across 24 projects** - Each consuming project hits the same issue
