## ADR Process

### Creating New ADRs

**For Technical Architects:**

1. Use [ADR Template](./template.md)
2. Document decision context and options
3. Record chosen solution and rationale
4. Update [Decision Log](./log.md)

### Reviewing ADRs

**For Engineering Teams:**

1. Review [Active Decisions](./active.md)
2. Understand implementation constraints
3. Check for related decisions in [Decision Log](./log.md)
4. Follow documented patterns
