## RFC Process

### Creating RFCs

**For Contributors:**

1. Use [RFC Template](./template.md)
2. Describe problem and proposed solution
3. Include implementation details and impact
4. Submit for community review

### Reviewing RFCs

**For Community:**

1. Review [Active RFCs](./active.md)
2. Provide feedback and suggestions
3. Discuss alternatives and concerns
4. Help refine proposals

### Implementation

**For Development Teams:**

1. Check [Accepted RFCs](./accepted.md)
2. Follow implementation guidelines
3. Create corresponding [ADRs](../adrs/index.md)
4. Update documentation
