# FLEXT worker scope and handoff

Read the [session router](../../.agents/commands/flext-law.md) and the active
assignment before effects. Global coordination, command, evidence and phase
rules remain their sole owners. This document supplies the FLEXT handoff delta.

## Assignment

Resolve the current Bead, repository, branch, physical workspace, runtime owner,
files, consumers, source epoch and acceptance contract. Placement and role come
from the current operator authorization; historical worker instructions do not
reassign an inline operator task or launch another agent.

Adopt and reconcile relevant staged and unstaged WIP. One writer owns each source
epoch. Agree changes with current writers through the selected coordination
channel; never mutate source while its generation or codemod publication runs.

## Verification

The root Make dispatcher and member routing are documented in
[root AGENTS.md](../../AGENTS.md). Universal deadlines, profiling, test selection
and result classification belong to the governance command owner. FLEXT family,
port and generator rules belong to branch-matched local flext-law and its ADRs.

Exercise the real changed public contract and retain native gate results for the
complete assigned scope. Do not widen a unit to the whole fleet by implication,
or omit a required consumer from its acceptance evidence. A source mutation or
integration update requires new proof for the affected candidate.

## Handoff and integration

Return changed owners and consumers, source and integration revisions, current
diff, command/cwd/exit/decisive output, runtime evidence and remaining red
findings to the selected task. A worker without landing authority returns that
evidence; the currently authorized integration owner completes review, merge and
post-merge proof. Local success, publication, integration and installed runtime
are separate receipts.

Members land before the superproject gitlinks advance. Retirement follows fresh
integration ancestry and complete WIP accounting through the global lane owner.
